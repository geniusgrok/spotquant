# Coin Metrics Community USDT source qualification and overlap

2026-10-07 UTC. Source registered for this read-only study as `coinmetrics_community_usdt_capest_price_v1`, separate from the frozen CoinGecko source. No source switch, historical receipt backfill, strategy outcome calculation, account command, trading or production wiring was performed.

## Local-only fixed response

Fixed public URL: `https://community-api.coinmetrics.io/v4/timeseries/asset-metrics?assets=usdt&metrics=CapMrktEstUSD,PriceUSD&frequency=1d&start_time=2020-01-01&end_time=2026-09-30&page_size=10000`. One independent keyless GET returned HTTP 200. Request started 2026-10-07 15:28:40.522 UTC and all bytes were received 15:28:41.330 UTC (23:28:41.330 UTC+8). The **336,432 raw bytes** have SHA-256 `18d511062eb636677960843006325a7f448f176faca0fbcddb8a9459ae4f99da`, matching the separately supplied source hint exactly. The raw response and receipt stay in the local restricted workspace; they are deliberately absent from this repository.

The exact JSON has one `data` array, no `next_page_url`, and 2,465 ordered, unique, non-null, positive `usdt` rows from 2020-01-01 through 2026-09-30 inclusive, all stamped `00:00:00.000000000Z`; there are no missing calendar days. This is a snapshot **received in 2026**, not a 2020–2026 first-receipt history. Store `historical_first_receipt=null`, `pit=false`, and the current receive clock separately. No revision history for earlier dates was obtained.

[Coin Metrics' definition](https://docs.coinmetrics.io/network-data/network-data-overview/market/market-capitalization#d) says `CapMrktEstUSD` is reported/estimated circulating supply multiplied by `PriceUSD`, whose daily close is at 00:00 UTC. The technically appropriate USDT quantity is `Decimal(CapMrktEstUSD) / Decimal(PriceUSD)` in **USDT units**. `CapMrktCurUSD` uses current issued supply and can include illiquid treasury/inventory; it is not a substitute. The reported circulating-supply input can come through CoinGecko, so this response is **not independent upstream validation**. Do not add chain-specific `usdt_eth` or `usdt_trx` figures to this aggregate quantity.

## Fixed-calendar comparison only

Against the already archived, separately received CoinGecko 365-day snapshot, exact UTC-date overlap is **358 days**, 2025-10-08 through 2026-09-30. On those same labels, median absolute percentage difference is 0.01928% for USD cap, 0.01853% for USD price and approximately 0 for inferred USDT supply; 95th percentile supply difference is 0.10106%, maximum 0.72153%. About 57.8% of overlapping inferred supply values agree to relative tolerance `1e-12`. Comparing Coin Metrics' supply to CoinGecko's prior or next date instead raises the median absolute difference to 0.00403% or 0.01142%, respectively. Same-date values are the most compatible by this diagnostic, but price construction and later revisions can still differ. The comparison does not certify when either historical value first became available. Reproduce the counts and aggregate differences with [`coinmetrics_usdt_source_overlap_20261007.py`](coinmetrics_usdt_source_overlap_20261007.py) and the two private/public receipts; the script refuses unpinned response hashes and checks UTC dates independently of host timezone.

## Use boundary

The [license text](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en) defines NonCommercial by commercial advantage or monetary compensation, rather than by whether a user is an individual. No express grant for strategy-profit testing or trading-system use has been established here; the older Terms of Use link currently redirects to a Talos product page and does not resolve that question. Keep the raw response local and the source outside economic/account tests and production until the intended use is clearly permitted. No key, paid plan or new agreement was created or accepted.

The existing CoinGecko strict-PIT receipt and conditional 365-day study retain their own identities and conclusions. A clearer license would remove only this **use-permission** block; historical first-receipt/revision timing and independent information/economics would still need separate evidence.
