usage: bind-phase-inputs.py [-h] --freeze FREEZE --report REPORT --export
                            EXPORT --production-profile PRODUCTION_PROFILE
                            --out OUT --kind {spot,perp} --phase PHASE
                            --export-label EXPORT_LABEL [--registry REGISTRY]
                            [--registry-sha256 REGISTRY_SHA256]

Bind an actual assessor export to one phase of an immutable parent freeze. No
producer, source freeze, export generation, profile rewrite, or account
action. The source-bound edge_assessment interface validates
project/spec/profile/raw links.

options:
  -h, --help            show this help message and exit
  --freeze FREEZE
  --report REPORT
  --export EXPORT
  --production-profile PRODUCTION_PROFILE
  --out OUT
  --kind {spot,perp}
  --phase PHASE
  --export-label EXPORT_LABEL
  --registry REGISTRY
  --registry-sha256 REGISTRY_SHA256
